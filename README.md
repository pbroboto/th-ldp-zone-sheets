# One Page TH-LDP

One-page sheets for the Thai low-distortion projection (TH-LDP) zones, in the
style of the Oregon (OCRS) one-pagers. Each sheet shows, for one LDP zone, the
combined scale factor (projection scale × elevation factor, using FABDEM heights
and the TGM2017 geoid) in seven ppm classes over a hillshade, the zone's
central meridian and origin latitude (or standard parallel), the main roads and
the province and Amphur seats, with the projection parameters in a side panel.

**Status: draft.** The sheets use the November 2569 (2026) zone definitions and
are marked "A - draft" until the TH-LDP committee approves them.

## Data sources and licences

The sheets and the scripts are built from third-party data. None of it is
stored in this repository; download it yourself.

| Input | Used for | Where to get it | Terms |
| --- | --- | --- | --- |
| **FABDEM** | elevations, hillshade, elevation factor | University of Bristol, <https://data.bris.ac.uk/data/dataset/s5hqmjcdj8yo2ibzi9b4ew3sn> (tiles; mosaic to `TH_FABDEM.tif`) | CC BY-NC-SA 4.0 |
| **GADM 4.1** | province outlines | <https://gadm.org/download_country.html> (Thailand, GeoPackage, `gadm41_THA.gpkg`) | free for non-commercial use; no redistribution |
| **TGM2017** | geoid undulation | <https://www.priabroy.name/download> (the author's weblog, where TGM2017 is available to everyone in Thailand); download the **`TGM2017.GTX`** file (NOAA VDatum binary grid), which is what the pipeline reads as `tgm2017.gtx`. The page also offers GGF, PGM, GEM, GFF, BIN, TIF, GRD, WPG and ISG, which the pipeline does not use | owner's terms (Royal Thai Survey Department) |
| **OpenStreetMap** | roads, provincial capitals, Amphur seats, airports, protected areas | fetched by the script from the Overpass API at run time (`overpass-api.de`) | ODbL, © OpenStreetMap contributors |

The first three can be downloaded from the internet, as listed. **OpenStreetMap
is different: nothing is downloaded by hand.** The script queries the Overpass
API for each zone and caches the answer under `zones/<zone>/` (not committed).
I have not verified what OSM's licence requires of the published sheets beyond
the attribution above, so treat that point as open.

The PDFs are derived from FABDEM and GADM, so they are shared under the same
non-commercial, share-alike terms as FABDEM: **CC BY-NC-SA 4.0**, with credit to
the sources above. The scripts are MIT-licensed (see `LICENSE`).

## Rebuilding the sheets

Needs QGIS 4.x (the scripts use its Python, PyQGIS and GDAL).

1. Put the inputs where the scripts expect them, under one root folder
   (`TH_LDP_ROOT`, default `D:\dev\One Page TH-LDP`):

       DEM\TH_FABDEM.tif
       TGM2017\tgm2017.gtx
       Thailand Admins\gadm41_THA.gpkg
       Province LDP Definition\ProvinceLDP.csv   (committee file: HASC_1, ISO_1, NAME_1, POP_Coverage(%); not in this repository)

2. Set `QGIS_HOME` if QGIS is not at `C:\Program Files\QGIS 4.2.1`, then run with
   QGIS's own Python:

       python-qgis.bat zones\zone_pipeline.py "Phrae"      # one zone
       python-qgis.bat zones\run_atlas.py                  # all zones

   Use `--skip-osm` to reuse cached OSM data, or `--osm-only` to refresh it.
   Sheets land in `output/`.

| File | |
| --- | --- |
| `zones/zone_pipeline.py` | the whole pipeline for one zone |
| `zones/zone_overrides.tsv` | the 90 zone definitions (PROJ strings, November 2569) |
| `zones/run_atlas.py` | all zones, resumable |
| `zones/run_nov.py`, `zones/run_layouts.py`, `zones/rebuild_layout_only.py` | full rebuild, layout-only rebuild |
| `zones/make_overrides_nov.py`, `zones/compare_csv.py` | build the definitions from the committee's PJ4/WKT files; compare them with the committee CSV |

The helper scripts (`run_nov`, `run_layouts`, `make_overrides_nov`,
`compare_csv`) still hold the author's own folder paths; edit them to suit.
